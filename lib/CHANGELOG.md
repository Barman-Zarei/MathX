# Changelog

## [0.1.0] - Unreleased
- Circles, sectors and ellipses.
- 2D shapes (square, rectangle, triangle, rhombus, parallelogram, trapezoid, regular polygon).
- 3D solids (cube, cuboid, cylinder, cone, sphere, prism, pyramid).
- Trigonometric, inverse and hyperbolic functions with degree support.
- Arithmetic, powers, roots and logarithms with any base.
- Number theory: gcd, lcm, primes, factorials, Fibonacci, combinations, permutations.
- Algebra: quadratic equations, linear systems, fraction simplification.
- Statistics: mean, median, mode, variance, standard deviation.
- Coordinate geometry: distance, midpoint, slope, polygon area and perimeter.
- Unit conversion (length, mass, time, angle, temperature).
- `formula()` reference (text or LaTeX) and a safe `evaluate()` for expressions.
- Accepts `int`, `float`, `Fraction` and `Decimal` where the maths allows it.
